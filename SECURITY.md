# Security policy

Vaulter AI is distributed through a private channel. Security fixes target
`main` and are released as a new version of every affected package.

Report vulnerabilities privately to Dmitry Vostrikov at
**dv.vostrikov@gmail.com**. Do not put credentials, provider API keys,
personal data, exploit details or customer documents in issues. Send a minimal
redacted reproduction, the affected package and version, and the impact.

Target acknowledgement is within three working days and initial assessment
within ten working days. Fix and disclosure dates are agreed privately.

Please test only systems you own or are allowed to assess, minimize data
access, and stop if customer data or model provider credentials are exposed.

The security model of the packages is described in
[docs/security.md](docs/security.md).
